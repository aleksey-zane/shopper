# Shopper

Плагин для [Claude Code](https://code.claude.com/docs/en/overview). Составляет меню под ваше питание и бюджет, считает, что нужно купить, и наполняет корзину в [Сильпо](https://silpo.ua).

Заказ плагин не оформляет и не оплачивает: корзину вы проверяете и оплачиваете сами на сайте или в приложении Сильпо.

## Что он умеет

- **Питание.** Считает калории, белки, жиры и углеводы для каждого, кто ест по плану. Учитывает аллергии, нелюбимые продукты и цель по весу.
- **Меню.** Подбирает блюда с рецептами на неделю, две недели или месяц и проверяет, что меню укладывается в бюджет.
- **Продукты дома.** Сначала использует то, что у вас уже есть.
- **Корзина Сильпо.** Находит товары, показывает список с ценами и только после вашего «да» кладёт их в корзину. Если в магазине чего-то нет, проверяет большой склад Сильпо. Любимые марки берёт, пока хватает бюджета.

## Что понадобится

- [Claude Code](https://code.claude.com/docs/en/setup) с командой `claude` в терминале. После установки плагина можно работать и в приложении Claude.
- Аккаунт Сильпо с доставкой по вашему адресу.
- Python 3.9 или новее. На Маке плагин сам предложит его установить. На других системах его можно взять на [python.org](https://www.python.org/downloads/).

Плагин проверен на macOS. На Windows и Linux он не проверялся.

## Установка

Откройте терминал и выполните две команды.

Добавить каталог с плагином:

```bash
claude plugin marketplace add aleksey-zane/shopper
```

Установить плагин:

```bash
claude plugin install shopper@aleksey-zane
```

Сильпо подключать отдельно не нужно: подключение ставится вместе с плагином.

## Первый запуск

1. Создайте пустую папку, например `shopper`, и откройте в ней Claude Code. В этой папке будут храниться ваши данные, поэтому дальше открывайте Claude в ней же.
2. Введите `/mcp`, выберите `plugin:shopper:silpo` и войдите в свой аккаунт Сильпо. Это нужно сделать один раз.
3. Введите `/shopper:menu`.
4. Ответьте на вопросы: кто ест, что любит и чего нельзя, сколько времени на готовку, какой бюджет. Вопросы идут по одному, всего около двадцати на одного человека.
5. Ответьте на вопросы о доставке: адрес, удобный день и время.
6. Посмотрите меню. Если всё нравится, ответьте «да». Если нет, напишите, что поменять.
7. Посмотрите список товаров с ценами. После вашего «да» они попадут в корзину Сильпо.
8. Оплатите корзину на сайте или в приложении Сильпо.

Первое меню собирается дольше обычного: плагин узнаёт цены на все продукты.

## Команды

Можно вызывать команды или просто писать своими словами.

| Команда | Что делает | Как сказать словами |
| --- | --- | --- |
| `/shopper:menu` | Составить, показать или изменить меню, показать рецепт | «сделай меню на неделю», «что сегодня на ужин?», «замени ужин во вторник» |
| `/shopper:profile` | Показать или изменить анкету | «бюджет теперь 5000», «добавь аллергию на орехи» |
| `/shopper:dietitian` | Показать дневные нормы | «сколько мне нужно калорий?» |
| `/shopper:pantry` | Записать продукты, которые есть дома | «дома есть литр молока и 5 яиц» |
| `/shopper:silpo-store` | Доставка, цены, любимые товары, корзина | «заполни корзину», «доставка в воскресенье» |

## Ваши данные

- Анкета, меню и цены лежат в папке `data` на вашем компьютере. На GitHub они не попадают.
- Из адреса сохраняются только город, улица и дом. Квартира, телефон, логин Сильпо и данные карты в файлы не записываются.
- Вопросы и ответы обрабатывает Claude, как в любом разговоре с ним.

## Откуда нормы питания

Нормы считаются по открытым источникам: Mifflin–St Jeor, ФАО/ВОЗ, EFSA, IOM, ISSN и WCRF. Полный список и пометки, где источника нет, лежат в [method.md](plugins/shopper/skills/dietitian/method.md).

Это общие рекомендации по питанию, а не медицинская консультация.

## Обновление

```bash
claude plugin marketplace update aleksey-zane
```

```bash
claude plugin update shopper@aleksey-zane
```

После обновления перезапустите Claude.

## Удаление

```bash
claude plugin uninstall shopper@aleksey-zane
```

Папка `data` при этом остаётся у вас.
